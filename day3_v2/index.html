2. Put traits on a common scale

5 minutes. Give each trait the same initial variance weight. scale() subtracts the column mean and divides by its sample SD:

Standardised value = (recorded value − column mean) / column SD.

A value of +1 means one SD above the retained-sample mean for that trait. Scaling does not remove outliers or make all traits equally important ecologically.

trait_scaled <- scale(trait_matrix)

round(colMeans(trait_scaled), 6)
apply(trait_scaled, 2, sd)

Check: all five means are approximately 0 and SDs approximately 1. Keep this one-line reason for scaling as a script comment: “We standardised to prevent differences in numerical scale from dominating the analysis.”

3. Build a PCA map

15 minutes. PCA finds axes summarising variation: PC1 captures the most, and PC2 the most remaining variation perpendicular to PC1. With five traits we can have five components; this map displays only two.

pca_result <- prcomp(trait_scaled, center = FALSE, scale. = FALSE)
summary(pca_result)

variance_percent <- 100 * pca_result$sdev^2 / sum(pca_result$sdev^2)
variance_table <- data.frame(
  PC = paste0("PC", seq_along(variance_percent)),
  percent = variance_percent
)
variance_table
sum(variance_percent[1:2])

We already scaled the matrix, so center = FALSE, scale. = FALSE avoids repeating that step. $sdev^2 supplies component variances; the recipe converts them to percentages.

Scores are isolate coordinates in pca_result$x. Run the supplied score and plotting sections; the four labels identify example isolates, while every retained isolate is plotted. coord_equal() keeps axis units equal.

scores <- data.frame(
  strainID = fungi_complete$strainID,
  Species = fungi_complete$Species,
  PC1 = pca_result$x[, 1],
  PC2 = pca_result$x[, 2]
)
head(scores)
label_data <- scores[scores$strainID %in% c("A", "DF56", "C31", "DF36"), ]

pca_plot <- ggplot(scores, aes(x = PC1, y = PC2)) +
  geom_hline(yintercept = 0, colour = "grey85") +
  geom_vline(xintercept = 0, colour = "grey85") +
  geom_point(size = 3, colour = "#245e49", alpha = 0.85) +
  geom_text(data = label_data, aes(label = strainID),
            nudge_y = ifelse(label_data$strainID == "DF56", 0.35, 0),
            vjust = -0.8, size = 3.5) +
  coord_equal() +
  labs(
    x = paste0("PC1 (", round(variance_percent[1], 1), "% of variance)"),
    y = paste0("PC2 (", round(variance_percent[2], 1), "% of variance)"),
    title = paste("Similarities among", nrow(scores), "fungal isolates"),
    subtitle = "PCA of five standardised traits; selected isolate IDs labelled"
  ) +
  theme_minimal(base_size = 12)
pca_plot

Record: the percentage shown by PC1 and PC2 together.

Check

PC1 shows 44.8%, PC2 20.8%, together 65.6%. The other 34.4% lies in PC3–PC5. Nearby points can therefore differ in traits not fully represented by this map.

4. Add trait arrows

10 minutes. Loadings, in pca_result$rotation, are trait weights on the PC axes. Positive and negative weights indicate directions; they are not p-values or percentages. Extract them and run the supplied arrow recipe.

loadings <- pca_result$rotation[, 1:2]
round(loadings, 2)
arrow_multiplier <- 2.5
trait_arrows <- data.frame(
  trait = rownames(loadings),
  PC1 = loadings[, 1] * arrow_multiplier,
  PC2 = loadings[, 2] * arrow_multiplier
)

pca_plot <- pca_plot +
  geom_segment(
    data = trait_arrows,
    aes(x = 0, y = 0, xend = PC1, yend = PC2),
    inherit.aes = FALSE,
    arrow = grid::arrow(length = grid::unit(0.18, "cm")),
    colour = "#884b24", linewidth = 0.7
  ) +
  geom_label(
    data = trait_arrows,
    aes(x = PC1 * 1.2, y = PC2 * 1.2, label = trait),
    inherit.aes = FALSE,
    colour = "#884b24", fill = "white", size = 3
  ) +
  labs(subtitle = "Five standardised traits; arrows show positive trait directions",
       caption = "Loading arrows multiplied by 2.5 for display; points are isolate scores")
pca_plot

All loading arrows use the same display multiplier, 2.5; it does not change the PCA. A point farther along an arrow’s direction has a higher reconstructed value for that trait in the two-PC approximation. Reversing both scores and arrows on an axis leaves the relationships unchanged.

Interpretation of the example

Principal component analysis (PCA) revealed substantial functional trait variation among the 28 fungal isolates, with the first two principal components explaining 65.6% of the total variance (PC1: 44.8%; PC2: 20.8%). PC1 primarily differentiated isolates associated with higher melanin production and cellulolytic enzyme activity from those associated with greater hyphal extension and spore abundance. PC2 was dominated by hyphal diameter, with spore abundance loading in the opposite direction. The orientations of the trait vectors suggest positive correlations between melanin production and cellulolytic activity, and between hyphal extension and spore abundance.

These vector relationships describe the PC1–PC2 projection, which omits 34.4% of the trait variation. Arrow angles do not give exact correlations, arrow lengths do not measure ecological importance, and point-to-arrow-tip distances are not trait measurements.

Break · 5 minutes. Save your script.

5. One exploratory clustering cut

10 minutes. Hierarchical clustering joins similar isolates using distances from all five scaled traits. We use Euclidean distance and complete linkage, where the distance between groups is the largest pairwise distance across members. Cut the tree once at k = 3 and note the group sizes.

trait_distances <- dist(trait_scaled, method = "euclidean")
cluster_tree <- hclust(trait_distances, method = "complete")
groups_k3 <- cutree(cluster_tree, k = 3)
table(groups_k3)

plot(cluster_tree, labels = fungi_complete$strainID,
     main = "Fungal similarity in five standardised traits",
     xlab = "Isolate ID", sub = "Euclidean distance; complete linkage; k = 3",
     ylab = "Complete-linkage distance", cex = 0.75)
rect.hclust(cluster_tree, k = 3, border = "#6a8f62")

The guided group sizes are 5, 18 and 5. Read join heights, not the left-to-right order of labels. This is a similarity tree, not a phylogeny; choosing three clusters does not prove that three natural fungal strategies exist.

The script also calculates mean scaled traits as a quick descriptive summary. No separate group-description exercise is needed.

cluster_profiles <- aggregate(
  as.data.frame(trait_scaled),
  by = list(cluster = factor(groups_k3)),
  FUN = mean
)
cluster_profiles

8. Help and downloads

If something does not run
  • File not found: extract the ZIP and open ABV_Day3.Rproj; check getwd() and list.files().
  • Object not found: run the earlier sections in order; R distinguishes uppercase and lowercase.
  • Missing or constant traits: use complete rows for the selected five numeric traits and inspect their SDs before scaling.
  • Different PCA orientation: axis signs may reverse; the matching scores and arrows should reverse together.
  • Overlapping labels: adjust label positions in the supplied plot recipe.

# Ecological Data Analysis with R

Guided tutorials for biology and ecology bachelor students, developed for **Smart Tools: Ecology with R and AI** at Freie Universität Berlin.

## Tutorials: 

| Day | Tutorial | Ecological focus |
|:---:|:---|:---|
| 1 | [R basics and data cleaning](https://mohanb96.github.io/Ecological-data-analysis-with-R/day1_v2/) | Compare water-stable aggregates in control and drought soil. |
| 2 | [Effect sizes, uncertainty and hypothesis tests](https://mohanb96.github.io/Ecological-data-analysis-with-R/day2_v2/) | Estimate the control–drought difference and assess its uncertainty. |
| 3 | [Fungal traits, PCA and similarity](https://mohanb96.github.io/Ecological-data-analysis-with-R/day3_v2/) | Explore which fungal isolates have similar combinations of traits. |
| 4 | [ANOVA and linear regression](https://mohanb96.github.io/Ecological-data-analysis-with-R/day4_v2/) | Compare soil treatments and describe litter mass loss across mixtures with different numbers of global change factors. |

## Getting started

1. Install [R](https://cran.r-project.org/) and [RStudio Desktop](https://posit.co/download/rstudio-desktop/) on your computer.
2. Open the tutorial for the course day and select **Download the student files**.
3. Extract the ZIP file into a folder on your computer. Keep its contents together.
4. Open the supplied project file, such as `ABV_Day1.Rproj`, in RStudio.
5. Open the starter script and save your own copy as `Day1_yourname.R`, changing the day number as appropriate.
6. Follow the tutorial in your browser and run the commands from your script in RStudio.
